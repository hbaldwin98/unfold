# Security Policy

## Supported Versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open
a public issue for suspected vulnerabilities or include credentials, tokens,
personal data, or exploit details in a public discussion.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an initial response within seven days.
